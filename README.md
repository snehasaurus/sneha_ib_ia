# Microland Limited - Financial Tracker 

This project was built to streamline budget tracking for an IT Services Company, Microland Limited. 
For privacy purposes all real company data is replaced with dummy names and files. 
The project tracks expenditure and budget forecasts of each department, allows each department to log expenditures, includes role-based access control mechanisms with unique log-ins and passwords for every employee, and allows authorised members to view graphs of each department's share in total budget allocation. 

## What I Learned
Through this project, I learned how to build a secure, full-stack web application by connecting a JavaScript frontend to a Node.js and Express backend with a MySQL database. I gained practical experience creating CRUD operations, using the Fetch API to exchange JSON data, and writing SQL queries to organize and aggregate information for role-specific dashboards.

I also learned that developing an application involves more than making its features work—it requires protecting user data and controlling access. I implemented password hashing with bcrypt, session-based authentication, and role-based access control for administrators, department heads, and employees. Additionally, I explored libraries such as Chart.js for data visualization, Nodemailer for email notifications, jsPDF for report generation, and dotenv for securely managing environment variables. Overall, this project strengthened my ability to connect multiple technologies, troubleshoot interactions between the frontend and backend, and think carefully about both usability and security. I also learned how to draft prompts and use artificial intelligence in an ethical manner to understand concepts rather than blindly replicate/copy other coders' work.
