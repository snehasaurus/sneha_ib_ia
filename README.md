# Microland Limited - Financial Tracker 

This project was built to streamline budget tracking for an IT Services Company, Microland Limited. 
For privacy purposes all real company data is replaced with dummy names and files. 
The project tracks expenditure and budget forecasts of each department, allows each department to log expenditures, includes role-based access control mechanisms with unique log-ins and passwords for every employee, and allows authorised members to view graphs of each department's share in total budget allocation.
